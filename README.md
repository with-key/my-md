# 3plit

로컬에 저장된 마크다운(`.md`) 파일을 브라우저에서 편하게 읽을 수 있는 뷰어입니다.
최대 3개의 패널을 나란히 놓고 여러 문서를 동시에 비교하며 읽을 수 있습니다.

---

## 설치 및 실행 가이드

프로그래밍 경험이 없어도 아래 순서대로 따라하면 사용할 수 있습니다.

### 1단계 — 사전 준비

아래 두 프로그램이 컴퓨터에 설치되어 있어야 합니다. 이미 설치되어 있다면 건너뛰세요.

| 프로그램 | 설명 | 다운로드 |
|---------|------|---------|
| **Node.js** | 앱을 실행하는 데 필요합니다 (v20 이상) | [nodejs.org](https://nodejs.org) 에서 **LTS** 버전 다운로드 |
| **Git** | 소스 코드를 내려받는 데 필요합니다 | [git-scm.com](https://git-scm.com) 에서 다운로드 |

> **설치 확인 방법**
>
> 터미널(맥: Terminal, 윈도우: PowerShell)을 열고 아래 명령어를 입력해 보세요.
>
> ```bash
> node -v
> git --version
> ```
>
> 각각 버전 번호가 출력되면 정상적으로 설치된 것입니다.

### 2단계 — 소스 코드 다운로드

터미널을 열고, 원하는 폴더로 이동한 뒤 아래 명령어를 차례로 입력합니다.

```bash
git clone https://github.com/with-key/my-md.git
```

다운로드가 끝나면 해당 폴더로 이동합니다.

```bash
cd my-md
```

### 3단계 — 필요한 파일 설치

```bash
npm install
```

처음 한 번만 실행하면 됩니다. 설치에 1~2분 정도 걸릴 수 있습니다.

### 4단계 — 앱 실행

```bash
npm run dev
```

아래와 비슷한 메시지가 나타나면 성공입니다.

```
➜  Local:   http://localhost:5173/
```

이제 브라우저(Chrome, Safari, Edge 등)를 열고 주소창에 **http://localhost:5173** 을 입력하면 앱이 열립니다.

> **앱 종료 방법**: 터미널에서 `Ctrl + C`를 누르면 종료됩니다.

## 사용 방법

### 마크다운 파일 열기

1. 앱이 열리면 왼쪽 사이드바 상단에 **Directory Path** 입력란이 보입니다.
2. 마크다운 파일이 있는 폴더의 **전체 경로**를 입력하고 **Open** 버튼을 클릭합니다.
   - 맥 예시: `/Users/홍길동/Documents/notes`
   - 윈도우 예시: `C:\Users\홍길동\Documents\notes`
3. 해당 폴더 안의 `.md` 파일들이 트리 형태로 나타납니다.
4. 파일 이름을 **클릭**하면 오른쪽 패널에서 내용을 볼 수 있습니다.

### 여러 문서 동시에 보기

- 패널 상단의 숫자 버튼(**1 / 2 / 3**)을 눌러 패널 개수를 조절할 수 있습니다.
- 파일 트리에서 파일을 **드래그**하여 원하는 패널에 **드롭**하면 해당 패널에서 열립니다.
- 패널 사이의 **구분선을 드래그**하면 패널 크기를 자유롭게 조절할 수 있습니다.

### 문서 내 링크로 파일 열기

마크다운 문서 안에 다른 `.md` 파일을 가리키는 링크(예: `[소개](./intro.md)`)가 있다면, 클릭 시 해당 파일이 새 패널에 열립니다.

### 특정 폴더 제외하기 (Ignore Patterns)

사이드바의 **Ignore Patterns** 섹션을 열면, 파일 트리에서 제외할 폴더를 glob 패턴으로 지정할 수 있습니다.

- 예: `node_modules`, `.git`, `build*`
- 패턴을 추가한 뒤 디렉토리를 다시 열면 해당 폴더가 트리에서 숨겨집니다.

### 테마 변경

사이드바 상단의 아이콘 버튼을 클릭하면 테마가 순환됩니다.

| 아이콘 | 모드 | 설명 |
|-------|------|------|
| 해 | Light | 따뜻한 톤의 밝은 화면 |
| 달 | Dark | 어두운 화면 |
| 모니터 | System | OS 설정을 따름 |

### 상태 자동 저장

마지막으로 열었던 폴더, 패널 배치, 최근 경로, 테마 설정은 브라우저에 자동 저장됩니다.
다음에 다시 접속하면 이전 상태가 그대로 복원됩니다.

## 자주 묻는 질문

**Q. `npm: command not found` 오류가 나와요.**
Node.js가 설치되지 않은 것입니다. [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치해 주세요.

**Q. `git: command not found` 오류가 나와요.**
Git이 설치되지 않은 것입니다. [git-scm.com](https://git-scm.com)에서 설치해 주세요.

**Q. 포트 5173이 이미 사용 중이라는 오류가 나와요.**
다른 프로그램이 해당 포트를 사용하고 있습니다. 기존 프로그램을 종료하거나, 터미널에서 `npx vite --port 3000`처럼 다른 포트로 실행하세요.

**Q. 파일 트리에 아무것도 안 나와요.**
입력한 경로에 `.md` 또는 `.markdown` 파일이 없는 경우입니다. 경로를 다시 확인해 주세요.

## 주요 기능 요약

- 로컬 `.md` / `.markdown` 파일을 트리 구조로 탐색
- 최대 3개 패널에서 동시에 문서 비교
- 드래그 & 드롭으로 패널에 파일 배치
- YAML 프론트매터 구문 강조 표시
- 마크다운 내 상대 링크 클릭 시 해당 파일 열기
- Shiki 기반 코드 구문 강조 (언어 자동 감지)
- 라이트 / 다크 / 시스템 테마 지원
- glob 패턴으로 특정 폴더 제외
- 상태 자동 저장 및 복원

## 기술 스택

| 분류 | 기술 |
|------|------|
| 프레임워크 | React 19 + React Router v7 (SSR) |
| 빌드 | Vite 7, TypeScript 5.9 |
| 스타일링 | Tailwind CSS v4, @tailwindcss/typography |
| 마크다운 | react-markdown, remark-gfm, remark-frontmatter, rehype-raw |
| 코드 하이라이팅 | Shiki (dual theme: github-light / github-dark) |
| 패널 레이아웃 | allotment (lazy loaded) |
| 드래그 & 드롭 | @dnd-kit/core |
| 폴더 필터링 | picomatch |

## 프로젝트 구조

```
app/
├── components/
│   ├── sidebar/      # 디렉토리 입력, 파일 트리, 최근 경로, Ignore 패턴
│   ├── panels/       # 패널 컨테이너, 개별 패널, 툴바
│   ├── markdown/     # 마크다운 렌더러, 코드 블록
│   └── dnd/          # 드래그 & 드롭 컨텍스트
├── lib/              # 타입 정의, 커스텀 훅 (테마, 패널, 경로, Ignore 패턴)
├── routes/           # 페이지 및 API 라우트
└── server/           # 파일 시스템 접근, 경로 검증
```
